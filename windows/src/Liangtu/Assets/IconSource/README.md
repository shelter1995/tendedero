# Generated icon sources

Produced with the built-in imagegen tool on 2026-10-25. The API did not expose a model selector; no claim that this is image2.5. Originals are retained here; scripts/package-icons.py only resizes and encodes PNG/ICO.

Application brief, revised 0.8.1: preserve coral clothes peg, curved blue clothesline, white photo stack, blue/teal mountains and gold sun on pale blue rounded square. Flat modern geometric color areas; remove thick shadows, bevels, ambient occlusion and texture. Generated by imagegen using previous composition as reference.

Tray, revised 0.8.1: the generated variants lacked clean small-size contrast. The production UI glyph is now code-native vector geometry on a 16px grid, in scripts/tray-art.py, matching the photo/peg identity with fewer details. Dark theme uses white rope/frame, pale cyan mountain and coral peg; light theme uses navy rope/frame, teal mountain and coral peg. Independent multi-resolution ICO files, with a real-size comparison at tray-size-preview.png. Original generated references are retained, but tray-generated.png is not the production tray source.
