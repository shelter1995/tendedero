## 运行
先从托盘退出旧版，再双击 dist/Liangtu-0.6.3/Liangtu.exe，或根目录 run.cmd。
本次使用独立的 0.6.3 发布目录，避免旧版运行时文件占用。用户数据仍保存在原目录。
run.cmd 会主动显示晾衣绳，重复启动会唤起已有实例。程序驻留系统托盘，左键图标显示/隐藏，右键打开设置。首次启动说明如何监听截图。
面向 Windows 10/11 x64，0.5 的便携包自带 .NET 8 Desktop Runtime，朋友的电脑无需另行安装 .NET。实时玻璃使用 Windows 11 合成接口；请保留程序目录中的 GlassNative.dll。源码构建另需 Visual C++ Build Tools 与 Windows SDK，已提供 scripts/build-native.ps1。
视频缩略图和裁剪使用本机 ffmpeg.exe（已检测到本机安装）；也可以放到程序 tools/ffmpeg.exe。没有 ffmpeg 时图片功能可用，视频显示占位缩略图，裁剪会明确提示缺少依赖。FFmpeg 不随压缩包分发。

## 操作
- 指针在屏幕顶边停留 250ms：展开；离开 500ms：收起。
- Ctrl+Alt+T：显示/隐藏，可在托盘菜单更改。
- Ctrl+Alt+S：框选截图，直接保存到本地收件箱。托盘 → 快捷键 → 框选截图，可修改、清除或恢复默认；显示/隐藏快捷键也有独立设置。
- 单击：等待系统双击间隔后复制原图；双击：用默认程序打开，不复制。
- 长按 450ms：图片标注，视频裁剪；中键或右键“快速查看”：预览。
- 拖入应用：提供原尺寸图片及文件；拖入文件夹：向 Windows Shell 请求移动。最终行为取决于接收方，取消不会删除。
- 右键：复制、打开、快速查看、标记、在资源管理器显示、保存桌面、取下/回收站、取下左右截图。
- 卡片左上角：收件箱文件移到回收站；外部文件只从晾衣绳取下。
- 大小：小/中/大；保留数量：适合屏幕/25/50/100；长列表在卡片上滚轮查看。
- Win+Shift+S 仍由 Windows 截图工具处理。勾选“接管截图”后，同时接收系统截图工具发布的剪贴板图片和截图/录屏文件夹的新文件；支持 Windows 重定向的 Screenshots 路径。其他来源的图片仍需开启“挂上复制的图片”。
- “挂上复制的图片”默认关闭，只处理纯图片，忽略文本、文件列表及常见隐私标记，不会采集开启前的旧剪贴板。

## 标注和裁剪
顶部图标栏选择工具，悬停查看名称；点击当前颜色的下拉按钮打开 Windows 标准调色盘，支持 RGB 与 16 个自定义色槽并记住颜色。B/H/L/A/R/O/T/C/E 切换画笔/荧光笔/直线/箭头/矩形/圆形/文字/裁剪/橡皮擦，V 切换平移。
Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做，Ctrl+S 保存。滚轮围绕指针缩放；空格+拖动、中键拖动或平移工具移动视图。+/- 缩放、Ctrl+1 100%、F / Ctrl+0 适应窗口；画布获得焦点后方向键平移，Shift+方向键大步移动。底部也有对应按钮。缩放和平移不改变导出图片的像素尺寸。
画笔、荧光笔、直线、箭头、矩形、圆形、文字、裁剪、局部橡皮擦、撤销和旋转。完成时原子写入，取消不写入。
JPEG/BMP/TIFF/GIF 按对应格式写回；多帧图片及 WebP 编辑结果另存为收件箱 PNG，保留原文件。
视频裁剪通过 FFmpeg 精确重编码，避免关键帧之前的画面残留。原文件仅在新视频成功生成后替换。失败不覆盖原文件。
视频预览：空格播放/暂停，左右键定位，拖动播放指针或点击进度轨道定位；Esc 关闭。
视频裁剪：拖动胶片两端手柄选择保留区，点击胶片定位；聚焦手柄后左右键每次微调 0.1 秒，Shift＋左右键调整 1 秒。起止时间支持 `mm:ss.fff`、`hh:mm:ss.fff` 或秒数输入，Enter/离开输入框应用。空格播放选区，Ctrl+S 保存片段，Esc 取消。保存片段会替换原文件。
视频选区调整支持 Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。一次拖动记为一步；“重置选区”恢复完整范围，也可撤销。历史仅用于当前编辑窗口内的选区调整，不用于恢复已经写回磁盘的视频。时间输入框获得焦点时保留文本自身的撤销操作。

## 本地数据
%LOCALAPPDATA%/Liangtu/Inbox：应用内截图和复制图片。
%LOCALAPPDATA%/Liangtu/settings.json：设置与晾衣绳文件路径。
%LOCALAPPDATA%/Liangtu/app.log：本地错误日志。
运行时不联网，无账户、遥测或自动更新。登录启动只有在用户打开托盘选项后才写入当前用户启动项。

## 复现范围和差异
已按源码移植绳子抛物线、三档尺寸、夹子/边框尺寸、轻摆、悬停缩放、按压、展开收起时序、复制提示、列表重排、已知截图区域飞入、丢弃下落、手势优先级。
Windows 系统托盘代替 macOS 菜单栏，顶边 3px 代替菜单栏悬停；Force Touch 用中键/右键替代。标注/预览/裁剪是 Windows 实现，字体、系统菜单/窗口框、系统提示音及玻璃材质与 Apple 原生实现有差异。
玻璃改为 Windows Composition 实时背景材质，叠加原版描边；输入区域也按轮廓裁剪。没有进行 macOS 逐像素材质对照。自动显示新图可避让全屏；已通过29组混合 DPI / 多屏模拟；真实双屏及更多接收应用仍未逐一验收。
截图目录监听保留 Windows 原有截图文件与缩略图设置，退出时无系统截图设置需要恢复。容量淘汰已恢复原版规则：每次新增最多淘汰一张，收件箱内旧图移至回收站；外部文件只从列表取下。主动降低保留量时批量处理。
已纳入原版十一语言资源与主要菜单映射；Windows 新增界面仍有中文文案。检查更新入口查看上游 macOS 发布记录，Windows 私人移植版通过本地构建更新。
因此这是可运行的 Windows 移植版本，不能标为原版所有 UI/UX 已逐像素、逐环境一致。详细验证见 docs/verification.md。
