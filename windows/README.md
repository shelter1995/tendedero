# Liangtu (晾图) for Windows

This directory contains the Windows app, tests, and packaging scripts. The full guide covers setup, everyday controls, local data, and building from source:

- [English guide](https://github.com/shelter1995/tendedero/blob/windows-port/README.md)
- [简体中文说明](https://github.com/shelter1995/tendedero/blob/windows-port/README.zh-CN.md)

Liangtu is a community port of [Tendedero](https://github.com/alejandrobujan/tendedero), with its own name and icon. [Download the 0.7.2 Windows pre-release](https://github.com/shelter1995/tendedero/releases/tag/windows-v0.7.2) for the installer, portable ZIP, and SHA-256 files.
