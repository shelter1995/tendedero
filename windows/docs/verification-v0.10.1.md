# 0.10.1 标注一致性与真实输入验收

日期：2026-10-27。对应用户手测反馈：视频标注面板与图片不同、文字输入后的拖动不同、增删标注使预览跳动。

## 修复

- 图片与视频共用 AnnotationControls 的工具定义/尺寸、八色色板、标准调色按钮、1–24px 笔宽滑块；文字编辑共用 AnnotationTextEditor 的原生输入、虚线框、20×22 DIP 左侧移动柄和边界约束。七套主题使用相同的工具按钮/命令按钮规则。视频保留适用的工具与播放、裁剪、元素时长区，并补齐荧光笔。
- 文字输入期间修改属性不重建输入框，不丢光标。左侧柄完成输入并进入整体拖动，整次移动可撤销。缩放结束重新读取对象属性；撤销/重做恢复对象后也同步字体、颜色、字号和笔宽。
- 时长轨道的占位只随窗口高度变化，空轨道显示提示。元素精确时间放入底部保留区，未选择时用 Hidden 保留空间。工具属性保持一行；对象增删、选中、重叠行数变化不会触发预览重新适应。
- 画布禁用隐式 IME 组合，文字输入框局部启用 IME。共享组件记录组合输入阶段，候选期间 Esc/方向键/空格/回车交给原生输入，避免关闭输入框或误触播放/工具。
- 修复滑块方向键误移对象/误定位、一次笔宽拖动多次撤销、空文字进入历史、点击播放残留输入框、Q后无法回到已用画笔等问题。滑块焦点下仍可Ctrl+Z/Y；空文字草稿留在实时编辑层，不进入已提交历史。

## 真实电脑交互

使用 Computer Use 的窗口绑定、真实鼠标拖拽和按键，在独立合成素材/数据目录中执行。没有通过给 TextBox.Text 赋中文来代替输入法测试。

- 微软拼音：实际按 n、i、空格提交“你”，按 h、a、o、空格提交“好”；打开候选后按 Esc，候选取消、已提交“你好”保留、文字仍在编辑；回车换行后继续拼音提交，并输入中文逗号，得到“你好\r\n好，”。观察到真实候选窗和 start/update/complete 事件。
- 图片对照：同样实际输入拼音 ni 并提交“你”，使用左侧柄拖动。图片和视频使用相同的 123×60 DIP 鼠标位移，两边的文档坐标乘各自缩放后均精确对应 123×60 DIP。
- 视频实际执行文字柄拖动、Ctrl+Z整次撤销、Ctrl+Y重做、角点缩放、圆点旋转、删除最后一个标注。预览位置与大小不变。
- 最终回归实际验证笔宽4→21，滑块保持焦点时Ctrl+Z恢复图形与4px控件，方向键仅将笔宽4→5，不移动对象和播放指针；Q/B/T切换不进入拼音组合，随后视频内输入框仍可实际弹出候选并提交“你”。
- 最终文字再次拖动123×60 DIP，角点放大后字号栏与对象同步为53.103448275862114；双击进入编辑，实际点击播放后输入框/移动柄退出；最后删除标注。

记录目录：artifacts/annotation-native-0101-data（中文多行/标点及图片对照），artifacts/annotation-native-0101-final-data（滑块同步问题的发现），artifacts/annotation-native-0101-verified（修复后滑块），artifacts/annotation-native-0101-complete（最终复验）。最后一组105条已加载状态仅有一组预览边界：X=337.94444444444446、Y=175、宽=431.1111111111111、高=242.5 DIP；最终对象数0，见该目录 acceptance-summary.json。

途中电脑交互授权曾超时，恢复后实际执行了上述操作；一次实体Esc停止后已停止接管，收到用户明确“恢复电脑交互，完成最终实测”后才继续。没有把中止阶段称为最终验收完成。
