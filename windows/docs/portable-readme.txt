晾图 0.10.7 · Windows x64 免安装修复候选包

1. 先从托盘退出旧版，再把整个 ZIP 解压到一个固定文件夹，不要直接在压缩包里运行。
2. 双击 Start.cmd（或 Liangtu.exe）。本包已带 .NET 桌面运行时，不需单独安装。
3. 软件驻留托盘。鼠标在屏幕顶边停留可展开晾衣绳。

首次设置
- 游戏勿扰模式：托盘菜单勾选后立即收起晾衣绳，暂停所有自动展开、操作提示音与后台通知；截图接收/保存继续。只有显示/隐藏快捷键（默认 Ctrl+Alt+T）能唤出，托盘左键、重复启动及 --show 不会唤出。晾图自身的截图快捷键暂时释放，退出勿扰后尝试恢复。状态跨重启保存；取消勾选恢复原有展开/声音设置，不补弹旧截图。
- 全屏游戏默认不自动弹出。升级到 0.7.3 首次启动会关闭旧版“在全屏 App 上”选项；新菜单名为“允许在全屏应用上自动弹出（含游戏）”，如需避让游戏请保持不勾选。手动快捷键和托盘显示仍可使用。
- 接管截图：接收 Windows 系统截图（Win+Shift+S）及截图/录屏目录的新文件。
- 挂上复制的图片：接收 Snipaste 等软件复制到剪贴板的图片，默认关闭。
- Ctrl+Alt+T 显示/隐藏，Ctrl+Alt+S 框选截图。两项都能在托盘的“快捷键”里修改或清除。

常用操作
- Win+Shift+S矩形框选在源位置与PNG校验通过后，从实际区域飞入；请开启接管截图与自动挂图。未知位置保留普通入场，游戏勿扰与全屏保护优先。
- 标注画好后自动选中；直接点击拖动，虚线框角点缩放、圆点旋转，附近按钮复制/删除/完成（复制立即创建副本）；Shift约束、Alt穿过对象绘制，双击文字输入。Ctrl+C/V复制粘贴、Ctrl+D重复、Delete删除、方向键微调；复制对象仅在当前编辑窗口内使用，保存图片后合成为像素。
- 托盘“外观主题”：白瓷工作室、暗房实验室、棉麻画室、柔彩积木四套新外观，以及晴空、纸与木、夜航，切换不会清空正在编辑的标注。
- 悬停图片时左上角收篮、右上角丢弃（默认确认后移到回收站）。数量增加自动缩小至可读下限，更多内容滚轮浏览；始终为右侧悬挂篮子留位。
- 夹子先到位并张开，图片沿曲线归位后才夹合；隐藏期间不会提前消耗新截图的入场动画。
- 取下与删除已分开：卡片左上角、全部取下和容量淘汰都保留文件；只有“移到回收站”并确认才删除。
- 绳子右侧或托盘打开图片篮子；支持待挂/全部、文件名搜索、Ctrl/Shift 多选、预览、批量挂回与保存副本。
- 长按图片夹子 450ms 松夹并变成置顶贴图；拖动移动、滚轮缩放，“挂回绳子”、关闭/Esc 默认挂回。独立篮子按钮用于收存；取下沿弧线飞入右侧篮子。游戏勿扰隐藏已有贴图，退出恢复。位置不跨重启保存。
- 单击松开立即复制；双击第一下也复制，第二下打开。长按进入标注，拖动分享。
- 文字工具：在图片上点击直接输入，Enter 换行；字体、字号、颜色、粗体、斜体可在输入前设置或选中文字后修改。拖动左侧移动柄调整位置，Esc 完成输入；工具栏支持撤销/重做。保存后文字合并到图片。
- 挂图、取下/删除、复制、进入编辑使用轻量单次短音，托盘“声音”可关闭。
- 标注工具放在图片上方，悬停查看名称。颜色下拉按钮打开标准调色盘。
- 画矩形/椭圆时按住 Shift 绘制正方形/正圆，拖动途中可按下或松开 Shift 切换。
- 画直线/箭头时按住 Shift，吸附到最近的水平、垂直或 45 度方向；同样支持途中切换。
- Ctrl+Z 撤销；Ctrl+Y 或 Ctrl+Shift+Z 重做；Ctrl+S 保存。
- 滚轮缩放；空格+拖动或中键拖动平移；F 适应窗口；Ctrl+1 实际大小。
- 视频预览：空格播放/暂停，左右键和进度条定位，Esc 关闭。
- 视频裁剪：一条胶片时间轴，两端手柄选择保留区；起止时间可精确输入。手柄支持左右键 0.1 秒微调，Shift 加速；Ctrl+S 保存片段，Esc 取消。
- 视频选区同样支持 Ctrl+Z 撤销、Ctrl+Y / Ctrl+Shift+Z 重做；一次拖动记为一步。“重置选区”恢复完整范围，也可撤销。
- 视频标注：使用文字、箭头、直线、矩形、圆形或画笔工具在画面上添加对象，直接选中后拖动、缩放、旋转；双击文字继续输入。属性栏与图片标注保持一致，编辑时自动暂停播放。
- 0.10.1统一了图片/视频的八色色板、1–24px笔宽滑块、文字选框与左侧移动柄，支持荧光笔；输入文字时直接拖动左侧✥移动。改字体/颜色保留输入框与光标，缩放和撤销同步属性。中文输入时Esc先取消候选，再按Esc完成编辑；Q/B/T等画布快捷键不被拼音组合截走。
- 时长轨道固定占位，空白时显示操作提示；精确显示时间放在底部。新增、删除和切换标注不会改变预览画面的大小与位置。
- 胶片上方的元素轨道控制显示时长：拖动整条移动时间，两端调整起止；选中后也可在“显示”时间框输入。点击时长条定位，轨道内左右键微调 0.1 秒，Shift 加速。裁剪和标注共用撤销重做。
- 保存时将文字与标注合成到视频；支持“取消保存”，失败或取消保留原文件和本次编辑内容。成功保存会替换原视频；如需保留未标注版，请先保存副本。保存后的标注不能单独修改，不提供跨次编辑工程或物体跟踪。

系统与功能范围
- 面向 Windows 10/11 的 x64 电脑；当前验收重点是 Windows 11。ARM64 原生版本尚未提供。
- 图片截图、复制、标注无需额外组件。
- 视频缩略图/裁剪需要 FFmpeg。本包未附带 FFmpeg；没有时不影响图片功能。
- 本试用包尚未进行数字签名。若系统提示来源未知，请先向发送者核实版本与校验值；不要关闭系统安全功能。
- SHA256 文件用于核对传输完整性，不等同于发行者数字签名。

数据与升级
- 0.8.2及以前首次升级须解压新包。0.9.0起可用托盘“Windows更新与升级”或导入完整portable ZIP（不要解压后导入）。程序校验版本、路径、大小与哈希，本地包需来自可信发布者。
- 升级前提示未保存编辑；退出后备份并替换程序，普通替换失败回滚。用户数据、tools与未知文件保留，备份/日志位于系统临时目录 Liangtu-updates。
- 图片、列表、快捷键与自定义颜色保存在 %LOCALAPPDATA%\Liangtu。
- 升级前从托盘退出旧版，再解压并运行新版。不要直接覆盖正在运行的程序。
- 删除解压目录即可移除程序；本地图片与设置不会随之自动删除。
- 不上传截图，无账号或遥测。仅主动检查/下载Windows更新时联网，没有后台自动安装。

问题反馈
请附上版本号、Windows 版本、各屏幕分辨率/缩放比例/排列方式、复现步骤。
错误日志位于 %LOCALAPPDATA%\Liangtu\app.log，分享前请检查其中的文件路径。

0.9.4补充：托盘“删除前确认”可随时恢复删除提示；跳过提示仍然移到回收站。X、右键和篮子批量操作使用相同的显示器居中确认和成功音效。棉麻/柔彩篮子更大、选中态扁平、柔彩照片底板更清晰；窗口与托盘图标跟随主题，外观窗口可导出ICO用于桌面快捷方式。
