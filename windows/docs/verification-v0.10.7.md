# 0.10.7 边框过渡与触发延迟

日期：2026-10-30。用户确认0.10.6不再闪屏，并批准同时优化边框突变和动作响应，继续保留防闪交接。

## 实现

- 主题相框、飞行和贴图面板共用同一份照片绘制。仅在照片外部过渡四边边距、圆角、材质和阴影；边距/阴影按物理屏幕单位计算，不随图片放大成厚边。
- 从真实 MaterialPanel 自身 OnRender 捕获背景、描边和材质，不包括子控件或照片。返场工具栏/说明使用现成矢量绘制树的冻结副本；不更改可见源窗口属性，也不截取用户照片。
- 出站后段约220ms变为贴图外观；真实工具栏在飞行窗口退休后120ms淡入。Esc先淡出控制条，反向变框。工具栏透明度改变不参与布局，图片位置不被挤动。
- 旧材质保持为底层，新材质逐渐覆盖。最初两层同时降低透明度的试验在中间帧使不透明边距alpha降到约192/255，已先用失败检查复现并修正，避免边框变透明而露出桌面。
- 450ms长按判定保留；取消判定后180ms和出站前140ms固定等待。移动约650ms。手动贴图回挂使用独立并行时序，不再串行等待绳子/夹子约560ms，普通截图的夹子先行时序不变。
- 源图和目标仍按不同 RenderingTime 交接；独立局部飞行窗口、落地交叠提交帧、取消/退出清理及原图保留继续沿用。临时外观在同步Mount、完成、卸载和隐藏路径释放。
- 飞行中切主题会更新真实目标布局/材质和图片矩形。独立复核发现的旧端点问题已先失败后修正；正常/取消均移除 Theme.Changed 订阅。

## 延迟与端点

同一受控窗口场景，计时从“长按已判定”及“Esc路由触发”开始，记录图片第一次实际移动，包含窗口准备和安全交接成本：

| 首次移动 | 0.10.6实现 | 本轮最终检查 |
|---|---:|---:|
| 合格长按后贴图 | 477ms | 138ms |
| Esc回挂 | 609ms | 84ms |

证据：`artifacts/pin-morph-red/results.txt` 与 `artifacts/morph107-verified-PinMorphChecks/results.txt`。此前约50ms是反馈设计目标，不是本轮首次移动实测值，也不是所有硬件承诺。移动前仍保留必要的渲染安全交接。

原先主题边距会随照片放大，最后一帧相框约1553×1155px，而真实贴图面板为1448×1040px；现在首尾边框与真实面板在1.5px容差内匹配。原始失败记录、材质alpha失败和主题切换失败分别见 `artifacts/pin-morph-red`、`artifacts/pin-morph-blend-red`、`artifacts/pin-morph-theme-red`。

## 验证

- 新增70项过渡检查：7主题首尾/中间帧、物理边距有界连续、返场反向、照片像素不重影、不透明边距无alpha空洞、工具栏说明捕获、复用已解码素材、快速回挂与普通截图时序分离、飞行中切主题重定向。
- 原20项防闪交接回归通过：绳子始终不超过700px，回挂源/飞行/目标的可见状态空帧0；包括跨屏、DPI维护、全屏手动状态、取消及文件保留。
- 显隐10项、选区24项、Windows剪贴板26项、第三方起点24项、核心与安全180项、篮子37项、主题飞行67项、动效28项均通过。总计486项。
- 独立只读代码复核确认已报告的主题切换端点问题解决，未发现其他确定的 Critical / Important。

命令：`scripts/test-feedback-motion.ps1 -RunName morph107-verified`、`test-safe.ps1`。日志位于 `artifacts/morph107-verified-motion.log`、`artifacts/morph107-safety.log`、`artifacts/morph107-BasketChecks`、`artifacts/morph107-MotionPolishChecks`、`artifacts/morph107-MotionPerformanceChecks`。

70张实际绘制的中间帧在 `artifacts/morph107-verified-PinMorphChecks/frames`；出站/返场文件分别为 `000.png`…`100.png` 和 `return-000.png`…`return-100.png`，棉麻中间帧和带完整工具栏的返场首帧已查看。

本轮是实际WPF窗口、原生尺寸、Rendering可见状态和绘制像素检查；长按判定后的入口和Esc窗口路由由测试调用，没有物理系统输入注入或用户桌面录像验收。不能据此承诺所有显卡、远程会话和物理多屏无慢帧。关闭系统动画时继续走静态交接，没有修改系统设置。

## 使用

候选包：`dist/Liangtu-0.10.7-Windows-x64-portable.zip`。先从托盘退出旧版，再解压启动或在原更新入口导入完整ZIP。run.cmd指向0.10.7。用户数据、旧版本目录和正在运行的进程没有被替换。
