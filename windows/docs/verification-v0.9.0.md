# 0.9.0 可编辑对象、整套主题、Windows升级

## 已实现
- 矩形、椭圆、线/箭头、画笔、荧光笔作为冻结几何对象保留。Q选择，拖动、Ctrl+C/V、Ctrl+D、Delete、方向键/Shift微调与右键菜单；文字同样可选择复制删除。历史包含几何/文字/局部擦除遮罩/裁剪/旋转；输出不含选择框。保存为图片后扁平化，复制对象是当前编辑窗口内部剪贴板。
- 晴空、纸与木、夜航三套覆盖完整界面的主题。帆布/编织/金属篮子与珊瑚/木/金属夹使用不同几何细节；窗口、编辑/视频、篮子、贴图、主题与更新界面统一。持久化和系统深浅跟随，共享绑定画刷避免重建编辑文档。高对比度优先，系统原生菜单仍跟随Windows。
- 仅手动发起的Windows更新：固定本项目GitHub源，Windows标签/版本/渠道/资产匹配、防降级、下载大小和SHA256校验、取消、本地包导入；安装版调用原安装器，便携版备份/原子替换/回滚。数据、tools、未知文件保留，原启动项由安装器维护。现有FFmpeg/FFprobe复用。

## 验收边界
测试没有替换用户正式安装或发布远程版本；真实用户新旧版在线端到端升级需要发布更高版本后验收。便携助手在隔离目录实测替换、回滚与文件保留；安装器仅构建/静态流程验证，本轮未重装用户机器。断电/强制终止可能需要手动恢复助手备份。主题美感仍以用户选择为准；旧图片中已栅格化的标注不能恢复为可选对象。
