# 0.9.2 高保真主题、截图动效与性能

## 已实现

- 使用MiniMax Design的Design Image 2.5 Pro，以用户认可的棉麻/柔彩原型生成两张透明生产图集。通过MiniMax FFmpeg拆分出篮子、衣夹开合、棉绳、空相框、表面纹理，并制作柔彩夹子的同材质配色变体。16个PNG实际编入应用，原图、任务和资源版本保留在artifacts/theme-production-092。没有把参考PicRope原始图片装进发行包。
- 棉麻标注界面采用横向文字工具栏、暖纸表面；柔彩采用左侧文字工具栏和柔圆画布分区。图片篮子采用虚拟化网格，棉麻选中项在下方，柔彩大图与操作在右侧。主题切换重排现有控件，保留文档、历史、多选和筛选；5000项网格只保留不超过30个容器。
- 标注浮动条合并为复制/删除/完成；48×30 DIP触点、8 DIP间隔和外留白。复制直接生成偏移副本，保留Ctrl+C/V/D。低缩放、窄图、裁剪与橡皮擦优先级均保留。
- 内置截图完成后立即显现绳子；独立、预热且按路径包围区域限定的透明窗口，从真实物理截图矩形沿三次贝塞尔飞到实际照片位置。保持夹子先到位张开、图到位再夹合。混合DPI、屏幕负坐标、隐藏转显示均有检查。
- 补位动画改用RenderTransform，不逐帧修改Canvas布局；连续移除从当前画面位置衔接。缓存图片解码、篮子绘制、几何和原生玻璃状态；篮子轻摆仅更新保留的旋转变换。绳子常驻窗口缩到顶部区域，桌面贴图飞行时临时扩展并在完成/取消后恢复。
- 删除确认改为默认取消的无系统提示音对话框，保留原有B组声音。应用、浅/深托盘图标及B音效均与改造前SHA256一致。
- 后台保存登记为受跟踪任务，退出/升级等待PNG、收藏与设置持久化完成。失败保留图像并阻止关闭，下次明确操作重试一次；并发截图预留不同文件名，避免同秒覆盖。

## 性能数据与边界

本机3840×2160、200%缩放、WPF渲染Tier 2、系统动画开启，合成数据测量：

- 绳子透明窗口为3840×700，常驻面积为整屏的32.4%。
- 24张图、180次更新的布局次数180→0；该次合成UI更新时间4.70→1.31ms。这是对布局工作量的测量，不等同整机FPS。
- 最新运行普通/棉麻/柔彩飞入中位帧间隔17.01/20.44/20.02ms，p95为21.49/26.21/25.76ms。仍出现38–46ms慢帧，不能宣称稳定60fps；桌面负载和硬件会影响实际表现。
- 两套篮子各120次摆动更新，绘制资源重建次数均为0。

精确源区域目前只由晾图内置框选提供。现有Win+Shift+S/Snipaste接入只取得图像，未验证到屏幕位置元数据，因此仍从绳子附近入场；没有以鼠标位置伪造截图矩形。后台显示仍受自动挂图/新图显示、全屏保护和游戏勿扰约束。用户常用截图方式的澄清尚未回复。

测试使用独立合成素材，不删除用户媒体、不替换系统剪贴板或正式安装。实际IME候选窗口、所有外部截图软件和真实多屏硬件组合未穷举；高对比度继续保留系统颜色路径。
