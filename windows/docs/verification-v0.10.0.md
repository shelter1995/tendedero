# 0.10.0 视频文字与定时标注候选版

日期：2026-10-27。用户授权在视频编辑中增加文字、标注和胶片上方的元素显示时长轨道，保持现有 UI/UX。

## 已实现

- 从原有“视频裁剪”入口进入视频编辑，支持文字、矩形、椭圆、直线、箭头和画笔。绘制后直接选择、拖动；选框四角缩放、圆点旋转；浮动操作只提供复制/删除/完成。双击文字继续输入，保留中文、多行、字体、字号、颜色、粗体和斜体。
- 复用图片编辑的 TextAnnotation、ShapeAnnotation、EditorViewport、TextSelectionFrame、ToolbarVisual 和主题资源。棉麻顶部带标签，柔彩左侧带标签，字体和笔宽在同一属性区上下文切换；保留系统标题栏。
- 胶片上方的元素条支持整体移动、两端调整和精确时间输入。多对象重叠时错行，轨道和胶片共用源视频比例。默认最多三行，紧凑窗口优先保留视频预览、将轨道收为一行滚动；没有对象时折叠。
- Q 选择、工具字母快捷键、Ctrl+C/V/D、Delete、方向键微调、Ctrl+Z/Y/Shift+Z、Ctrl+S 与图片操作一致；视频保留空格播放/暂停、滚轮缩放、中键平移、F 适应窗口。轨道左右键调整 0.1 秒，Shift 调整 1 秒，不触发取帧；单击时长条可定位。
- 标注与裁剪共用有界元数据历史，一次拖动为一步，不缓存视频帧。播放只更新现有视图的显隐；暂停后沿用原有停止空刷新的机制。
- FFmpeg 导出按裁剪区间截取标注并平移到输出时间，起点闭、终点开。使用 WPF 原生排版生成局部透明 PNG，避免逐帧 WPF 合成及每个元素的全尺寸位图。文字内容不进入命令/过滤图字符串；进程通过 ArgumentList 传参。
- 导出支持进度和取消，编码成功后才替换原视频。失败/取消保留原文件、裁剪和对象，恢复编辑与再次保存；升级前的未保存保护也纳入视频标注。

## 性能记录和限制

本机 i7-13700K，WPF/FFmpeg 8.1.3-Jellyfin，640×360 合成素材：50 个保留图形、1200 次显隐时间更新约 4.02ms，UI 线程累计分配 102040 字节；同一批对象视图保留，未生成视频帧位图。这是更新逻辑的合成测量，不是桌面 FPS、视频解码或整机内存测试。

最终拖动诊断：240 次批量选区更新无旧位置通知；暂停 600ms 的通知为 0；突发拖动合并为最新位置，松手立即提交；持续拖动在 120ms 读取到请求/媒体位置均为 6 秒。首轮曾有一次 120ms 固定时序断言失败，随后加入实测位置记录，诊断和最终回归均通过；保留该时序敏感性，不据此承诺稳定 60fps。

本轮已渲染检查七套主题、窄窗口和中文导出图片，位于 artifacts/video-annotations-final。电脑交互工具对隔离编辑器的应用授权等待超时，未完成真实鼠标拖拽和输入法候选窗口验收；混合 DPI 硬件、全部旋转元数据视频、低端机器、4K/60fps 和长时间编辑内存仍未穷举。MediaElement 的显隐预览沿用普通播放时钟，不承诺逐帧回调；导出按解码帧时间判断。
