# 0.8.2 独立夹合、自适应布局与悬挂篮子

## 修正
卡片旧计时器在构造时启动，隐藏时耗尽；改为第一次实际可见才开始，绳子首次展开留约320ms前导。夹子180ms就位，80–240ms张开；图片240–1120ms归位；1120–1320ms夹合。夹子与图片各有变换层，不再一起飞。已知来源用真实物理坐标，未知来源用明显的下方入场。

夹子采用前后重叠面、斜侧视和侧面弹簧。应用图标保留，托盘夹子同步斜侧面与深浅主题对比。篮子浅色编织篮身/蓝灰边/挂带锚定绳子，持续小摆动，展开和入篮产生阻尼摆动。

右侧保留篮子区域；照片随数量缩小到0.55比例下限，仍放不下时滚轮浏览。图片绘制与命中裁剪均限于图片区。原生玻璃独立窗口不受WPF Clip约束的问题已复现：对越界玻璃面使用WPF本身的受裁剪边框回退，避免原生背景伸入篮子区；复制提示玻璃同样检查。

左上收篮/右上丢弃为24px悬停动作，浅色低调底板；丢弃仍弹出明确回收站确认，文件保留规则不变。窄长图片的两个操作使用最小64px动作跨度以避免重叠。

## 动效参考
阅读了[GSAP Easing](https://gsap.com/docs/v3/Eases/)与[Timeline](https://gsap.com/docs/v3/GSAP/Timeline/)官方资料，借鉴分段时间编排和缓动思路。运行时使用WPF、三次贝塞尔路径与cubic-bezier(.25,.1,.25,1)时间曲线，没有引入GSAP/JavaScript/WebView依赖。

## 原生退出清理
首次扩展UI测试曾在全部断言结束后出现0xC0000008，另一次未正常退出。检查发现原生队列关闭会泵消息，而托管指针仍保留所有权；改为先清空托管所有权，并在关闭Compositor/队列前释放其子层、画刷、根视觉和目标。此后受控UI回归与安全套件均正常退出。无法仅由静态检查断言先前错误的唯一根因；记录现象、修改与退出码，不把断言通过等同于进程健康。

测试只使用工作区合成媒体，无用户剪贴板写入。真实多屏热插拔和主观动作质感仍需试用确认；提供界面帧预览供检查。旧版目录及源码/原生库备份保留。
