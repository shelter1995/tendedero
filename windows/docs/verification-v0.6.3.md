# 0.6.3 扁平图标与视频选区撤销/重做

日期：2026-10-24。用户最终确认统一使用扁平单色线性图标。

## 视觉统一

- 图片标注、图片/视频预览、视频裁剪共用同一套 18px 图标、24 单位光学网格、1.45 单位线宽和圆角线帽。
- 去掉工具图标的材质填色、渐变、立体外框、高光和阴影。普通工具按钮透明，悬停/选中为轻量底色；键盘焦点仍清楚可见。
- 保留图片标注、图片裁剪、视频裁剪的不同语义图形；图片色板仍显示真实颜色，便于选择标注色。
- 视频裁剪头部使用与图片标注完全相同的撤销/重做图标与提示；原来的圆箭头其实是重置选区，现改为明确的“重置选区”文字操作。

## 视频历史行为

- Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。无可撤销/重做操作时按钮禁用。
- 一次完整手柄拖动只记为一步；键盘微调、精确时间应用和重置也记录选区历史。
- 撤销/重做同时恢复起点与终点，不受当前范围边界影响。
- 无变化操作不产生历史，也不清空重做；撤销后进行新的编辑会清空旧重做分支。
- 历史最多保留 100 个状态，只存两个时间值，不复制视频数据。
- 历史只覆盖当前窗口内的选区修改；不是对已保存文件的版本恢复。文本框聚焦时保留文本本身的撤销行为。
