晾图 0.10.7 · 安装器 r1 · 使用说明

【安装】
双击 Liangtu-0.10.7-Setup-x64-r1.exe，按中文向导安装。
支持 Windows 10 / 11 x64；不需要另装 .NET，也不需要管理员权限。
默认包含图片功能。选择视频功能时会联网下载约 65 MB 的 FFmpeg 组件；优先南京大学镜像，失败后自动尝试官方源。不选视频组件可离线安装图片功能。
所有下载来源都校验固定 SHA-256。若全部失败，可重试，也可返回上一步取消视频组件；以后重新运行安装包补装。
也可先从下面地址下载组件，将 ZIP 原样放在安装程序旁边（不要解压），再运行安装程序，即可离线安装视频组件：
https://mirrors.nju.edu.cn/jellyfin/files/ffmpeg/windows/8.x/8.1.3-1/win64/jellyfin-ffmpeg_8.1.3-1_portable_win64-clang-gpl.zip
文件名必须为 jellyfin-ffmpeg_8.1.3-1_portable_win64-clang-gpl.zip，安装器会自动校验。

【游戏勿扰模式】
托盘菜单勾选“游戏勿扰模式”，立即收起晾衣绳并暂停所有自动展开、提示音和后台通知；截图仍保存。仅显示/隐藏快捷键（默认 Ctrl+Alt+T）能唤出，晾图自身的截图快捷键暂时停用。托盘可随时取消勿扰，恢复原有设置，不补弹旧截图；勿扰状态跨重启保留。

【游戏全屏避让】
从0.7.2及更早版本升级时，会关闭旧版允许全屏自动弹出的设置。托盘 → 放下晾衣绳 → “允许在全屏应用上自动弹出（含游戏）”应保持不勾选。无边框全屏、短暂叠加层及跨屏移动已增加保护；手动快捷键/托盘显示仍可主动打开。

【第一次使用】
安装结束后启动晾图，在欢迎窗口勾选“接收 Windows 系统截图和录屏”。
软件驻留系统托盘。把鼠标停在屏幕顶边，或者按 Ctrl+Alt+T 显示晾衣绳。
Ctrl+Alt+S：框选截图。Win+Shift+S：继续使用 Windows 截图工具。
其他软件复制的图片，需要在托盘勾选“挂上复制的图片”。

【常用操作】
Win+Shift+S矩形框选可从实际区域飞入绳子；请开启接管截图与自动挂上新截图。不会接管系统快捷键。取消、特殊模式或来源校验失败时保留普通入场；游戏勿扰与全屏保护优先。
标注画好后自动选中；直接点击拖动，虚线框角点缩放、圆点旋转，附近按钮复制/删除/完成（复制立即创建副本）；Shift约束、Alt穿过对象绘制，双击文字输入。Ctrl+C/V复制粘贴、Ctrl+D重复、Delete删除、方向键微调；V仍是平移。复制对象仅在当前标注窗口内使用，保存图片后合成为像素。
托盘“外观主题”提供白瓷工作室、暗房实验室、棉麻画室、柔彩积木四套新外观，以及晴空、纸与木、夜航，也可跟随Windows深浅色。
鼠标停在图片上后，左上角收纳到篮子，右上角叉号移到回收站（默认确认，可勾选以后不再询问）。图片增多时自动缩小；达到可读下限后滚轮浏览，图片不会挤入右侧篮子区。
普通截图按“夹子到位并张开 → 图片归位 → 夹合”播放；桌面贴图回挂时图片与绳子/夹子并行，边框连续过渡，工具栏单独淡入。篮子挂带固定在绳上，篮身轻摆。
取下、全部取下、绳上容量淘汰均保留原文件；图片篮子从绳子右端或托盘打开。只有明确选择“移到回收站”并确认才删除文件。
篮子支持待挂/全部、文件名搜索、Ctrl/Shift 多选、预览、批量挂回、保存副本。关闭“自动挂上新截图”后仍收集到篮子。
长按图片上方夹子 450ms 松夹并钉在桌面；拖动移动、滚轮缩放。“挂回绳子”、关闭或 Esc 默认挂回；另有独立篮子按钮用于收存。取下沿弧线飞入右侧篮口。游戏勿扰隐藏贴图，退出恢复；贴图位置暂不跨重启保留。
首次升级会保留原挂图、纳入收件箱现有媒体，并生成 settings.before-basket.json 设置备份；不会从回收站恢复旧版本已删除的图片。
单击松开立即复制；双击第一下也复制，第二下用默认程序打开。中键预览，长按标注图片或裁剪视频。
文字属性与颜色共用一行，可调整字体、字号及 B/I 粗体斜体按钮；输入后选中文字仍可调整并拖动位置。
图片标注和视频选区都支持 Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做。
视频预览：空格播放/暂停。裁剪时拖动胶片两端手柄，或输入起止时间。
Ctrl+S 保存，Esc 取消/关闭。视频“保存片段”会替换原文件，请先确认需要保留的内容。

【升级与卸载】
0.8.2及以前首次升级到0.9.4仍用此安装包。之后可通过托盘“Windows更新与升级”检查Windows发布或导入完整Installer ZIP。预发布需主动勾选，低版本不会安装。
更新入口会保留数据和已有视频组件；普通文件替换失败会回滚。缓存、日志和备份在系统临时目录 Liangtu-updates，断电/强制结束后可据此恢复。
升级前保存编辑，从托盘退出晾图，再运行新版安装程序。
默认不开机自启；有需要可在托盘菜单自行启用。之前已开启时，安装器会更新已有启动项的程序路径。
可从 Windows“已安装的应用”卸载。卸载时默认保留软件设置和收件箱图片，可选择一并删除；删除不可撤销，外部文件夹中的原图不受影响。取消卸载不清理数据。已有旧版安装用户需通过新版安装包升级，才能更新卸载选项。
数据目录：%LOCALAPPDATA%\Liangtu
日志：%LOCALAPPDATA%\Liangtu\app.log
重新安装时取消视频组件不会删除之前已经安装的视频组件。

【版本与来源】
此版本尚未代码签名，Windows 可能显示“未知发布者”。请核对发送者及提供的 SHA-256 文件；不要关闭系统安全功能。
没有账号、遥测或截图上传。首次选装视频组件需要网络；主动检查和下载更新时访问GitHub，没有后台自动安装。
程序与第三方许可证在安装目录 licenses 中。
