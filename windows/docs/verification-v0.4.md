# 0.4 标注工作区修订 · 2026-10-23

## 用户要求与实现

- 图片上方改为紧凑图标工具栏，移除左侧文字工具列表和大标题区。保留矩形、圆形、直线、箭头、画笔、荧光笔、文字、裁剪、橡皮擦，增加平移工具。动作栏提供撤销、重做、旋转、关闭、保存。悬停 350ms 显示名称和快捷键；控件有可访问名称、选中/禁用/焦点状态。
- 颜色包含八种常用色和自定义入口。点击带下拉箭头的当前颜色打开 Windows 标准 ColorDialog，默认展开自定义调色区，可使用色谱、RGB 输入、16 个自定义色槽。确认的当前颜色和自定义槽持久化；取消不改变当前颜色。
- 画布支持滚轮围绕指针缩放，空格+左键拖动或中键拖动平移，也可选择手形工具（V）拖动。底部提供四向平移、缩小、放大、100%、适应窗口。
- 快捷键：Ctrl+Z 撤销；Ctrl+Y / Ctrl+Shift+Z 重做；Ctrl+S 保存；+/- 缩放；Ctrl+1 实际大小；F / Ctrl+0 适应；画布获得焦点后方向键平移，Shift+方向键大步平移。
- 历史记录同时保留标注图像和对应的无标注底图，使裁剪/旋转后的橡皮擦仍能正确恢复原图。最多保留 30 步，新操作清除重做分支。取消或零面积裁剪不改变历史。撤销回原始状态后不再提示未保存。

## 实现边界

EditorViewport 将缩放/位移放在画布父容器，绘制坐标始终是图像像素；导出始终来自原尺寸的已提交图片，不截取视口、不受缩放影响。失去鼠标捕获或窗口失活会取消未完成笔画并释放自己的捕获。缩放范围 1%–1600%，默认适应不会放大小图。

这是视图平移和缩放，不是拖动已提交的某一条标注。绘图保持现有栅格提交方式；本次没有增加对象级选择、移动或编辑。
