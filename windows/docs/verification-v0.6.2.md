# 0.6.2 轻拟物工具栏统一

日期：2026-10-24。用户反馈重复关闭叉、图片/视频同图标不同语义，以及编辑工具栏图标过大、风格不统一。

## 设计选择

选择轻拟物方向：18px 矢量图形置于固定 24 单位光学网格，32px 点击区；圆角、统一描边、微弱上下明暗、顶部高光、底部薄阴影，以及明确的按压和选中状态。工具局部采用木质铅笔、荧光笔、橡皮、金属剪刀和保存盘片的克制材质色，整体仍沿用黑白灰与冷蓝。

查阅了用户提供的 [naive-icons 仓库](https://github.com/guokaigdg/naive-icons) 的风格说明与图标目录作为参考。本次实现是本地 WPF 矢量绘制，没有复制该库 SVG、安装 React 包或新增运行时依赖。

## 语义整理

| 场景 | 图形 | 提示 |
| --- | --- | --- |
| 图片预览进入编辑 | 图片与铅笔 | 图片标注 |
| 图片编辑裁剪工具 | 裁剪取景框 | 图片裁剪 · C |
| 视频预览进入编辑 | 剪刀 | 视频裁剪 |
| 视频编辑模式标记 | 同一剪刀 | 视频裁剪 |

预览切换图片/视频时，图形与提示同时更新。图片预览、视频预览、图片标注、视频裁剪都移除了内容区工具栏的关闭叉；系统标题栏与原有 Esc 行为保留。视频保存区域的“取消”仍表示取消本次编辑。

## 实现

- 新增 `ToolbarVisual` / `ToolGlyph`，所有相关窗口共享图标比例、描边、材质、提示及按钮创建规则。
- 原先每个 Path 各自拉伸至 21px，容易造成视觉大小不一；现在固定图标视口，几何图形保留原比例。
- 工具按钮样式独立命名，普通对话框按钮、色板色块等不套用拟物工具按钮模板。高对比度下去除材质填充与装饰阴影，使用系统语义色。
- 未改视频拖动合并、取帧缓存、媒体保存逻辑或图片编辑算法。

## 验证

- 新增两个行为回归在修改前均失败：存在重复关闭按钮；图片标注与视频裁剪使用相同图形。修改后均通过。
- 最终安全回归 **76 项通过**，结果 `artifacts/toolbar-final-data/results.txt`，涵盖图片标注、历史、快捷键、多屏布局与上述新检查。
- 视频回归 **14 项通过**，结果 `artifacts/toolbar-video-final/results.txt`，涵盖预览、保存、取消、失败保护和音轨保留。
- 图片编辑标准与紧凑窗口已渲染检查；当前桌面实际视频预览/裁剪窗口已检查，剪刀入口能正确进入裁剪，内容区无重复关闭叉。
- 构建 0 警告、0 错误；便携包 483 个文件哈希、自带 .NET/WPF 与原生 DLL 校验通过。
