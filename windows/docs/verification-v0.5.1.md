# 0.5.1 Shift 等比例形状 · 2026-10-23

矩形与圆形工具按住左右任意 Shift 时约束宽高相等，生成正方形与正圆。支持拖动途中按下/松开 Shift，即使鼠标没有继续移动也更新预览；松开鼠标时以当时 Shift 状态提交。

以鼠标按下位置为固定角，使用较大的拖动分量确定边长，支持四个拖动方向。在画布边缘按两个方向的可用空间同时限制边长，避免出现长方形或反向拖拽。零面积操作不提交历史、不破坏重做记录。约束在原图像素坐标中计算，与视图缩放和平移无关；裁剪、画笔、直线等其他工具保持原行为。

新增四项回归：四方向与自由比例切换；画布边界/向外拖拽；矩形即时切换、提交像素、撤销/重做；圆形相同完整流程。先运行缺失约束的实现，前两项失败；完成后通过。真实 WPF 元素的预览和提交像素一致，缩放平移后也不改变形状比例。

日志：artifacts/shift-build.log、artifacts/shift-data/results.txt。未注入桌面键盘鼠标；真实 Shift 按键事件操作仍需试用确认。
