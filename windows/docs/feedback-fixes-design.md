# 2026-10-23 试用反馈修订

范围：应用图标、托盘/图片系统右键菜单、关于/快捷键弹窗、外部截图导入、两组快捷键配置、标注工作区。

采用已有 WPF + Win32 架构。菜单模型保留命令构造，显示交由 HMENU，避免全框架迁移；窗口使用统一控件资源、清晰中文字体、不透明表面。图标采用相片挂在绳上的几何形象，并生成多尺寸 ICO。

剪贴板优先读取 PNG，保留其透明度；无 PNG 时读取 DIB 的 RGB 数据，备用 CF_BITMAP 不把未定义的高字节作为透明度。剪贴板占用时有限重试，以事件代数和序号防止读取过期内容。系统截图通过剪贴板所有者识别，受“接管截图”控制；其他软件复制图片仍受独立选项控制。保留隐私标记、文本、文件、自身复制过滤。系统文件夹使用 Known Folder 路径补充传统路径。

两组快捷键分别保存、禁用和恢复，冲突校验失败恢复旧注册并在弹窗内提示。编辑器保留现有绘图和原子保存逻辑，增加工具选中态、颜色选中态、笔宽与快捷键提示。

验证：先以合成剪贴板数据复现，再运行回归；不读写用户剪贴板、不注入桌面输入。使用离屏 WPF 渲染审阅窗口布局。实际 Win+Shift+S / Snipaste 交互若未执行须明确标注。
