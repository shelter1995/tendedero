# 0.7.4 游戏勿扰模式 · 2026-10-25

## 行为

托盘菜单首项增加“游戏勿扰模式”，默认关闭，状态持久化。开启后立即收起晾衣绳与玻璃层，停止正在播放的应用提示音，作废待执行的应用内截图请求。只保留显示/隐藏全局快捷键作为唤出入口（默认 Ctrl+Alt+T，可自行修改）；托盘左键、托盘显示菜单、重复启动、--show、欢迎界面及顶边/新内容均不能唤出。

系统截图、Snipaste 图片与文件夹接收继续保存；勿扰中不自动跨屏移动。不改写 Sounds/HoverReveal/NewReveal/OverFullscreen 等既有偏好，退出后恢复其原值，不重播提示音或补弹已有截图。托盘文字标识状态，自动展开/声音菜单显示暂停，截图命令禁用。捕获快捷键在勿扰时注销，退出后重新注册；若冲突则提示，保存的组合键不改变。

声音由统一策略控制，挂图、取下、复制、进入编辑都静默，声音资产和原有映射不变。后台错误和托盘通知只记录日志；主动打开的编辑窗口与用户发起的保存/关闭确认不被强制关闭，以免丢失编辑。

手动快捷键唤出后，可正常查看和操作截图；新截图到达不会关闭或挪动用户刚唤出的绳子，但仍无提示音。收起后继续保持勿扰。已有显示快捷键未设置/被占用时，可在托盘配置快捷键，或取消勿扰恢复普通使用。

## 验证

新增9项回归：只允许快捷键来源、声音/通知策略、设置保存与偏好独立、进入时立即隐藏、非快捷键入口全拦截、真实文件入库继续、手动显示不受新图扰动、托盘状态/禁用项、退出不补弹且恢复原偏好。先在未实现策略上复现两项失败，修补后通过。

日志：artifacts/game-mode-build.log、artifacts/game-mode-data/results.txt。使用受控设置、真实隐藏 WPF 窗口和工作区合成图片；没有注入真实键鼠、播放音频或修改用户剪贴板。真实游戏中热键注册/提示音的最终体验仍需试用确认。

这是独立于游戏检测的强制勿扰开关，即使全屏检测暂时失效，自动显示仍会被模式本身拦截。正常模式保留0.7.3的全屏保护。

安装用户退出旧版后运行0.7.4升级安装包；便携入口为dist/Liangtu-0.7.4/Liangtu.exe或根目录run.cmd。
