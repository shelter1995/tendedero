# 0.5.2 Shift 直线/箭头方向约束 · 2026-10-23

直线和箭头支持 Shift 吸附到最近的 45° 倍数方向，即水平、垂直和四个对角方向。拖动途中按下/松开左右 Shift 可即时切换，鼠标不移动也会更新预览；释放鼠标时根据最终按键状态提交。箭头头部由约束后的端点及方向生成。

吸附将指针投影到最近的方向射线，触及画布边缘时沿射线缩短，避免单独裁切 X/Y 破坏角度。零长度向外拖拽不产生箭头残影，也不清除重做记录。原有矩形/圆形 Shift 约束保留，其他工具不受影响。

新增四项回归覆盖八方向吸附/自由方向、边界裁切与零长度、直线即时切换/预览提交/历史、箭头头部对齐/相同完整流程。几何回归在缺失吸附的实现上先失败，完成后通过。WPF 集成检查在缩放平移后的视图中比较预览与最终像素，并验证撤销/重做。

日志：artifacts/angle-build.log、artifacts/angle-data/results.txt。没有注入真实桌面键鼠事件；按键操作链路仍可在试用时复核。
