## 自动验证
- Core.Tests：布局、比例、窄屏/宽屏容量、居中定位、延迟复制、双击不复制、长按互斥、拖拽互斥、取消、路径边界与媒体过滤。
- Windows SelfTest：重复文件、外部文件取下不删除、损坏图片、会话保存、原子覆盖、跨线程位图、非激活置顶、收起窗口、可视渲染。
- 回归测试：JPEG 编码、原图拖放、启用监听后新建目录、覆盖同一路径刷新、隐藏时手势计时、多帧另存、位置擦除、非关键帧精确裁剪、视频首次播放。
- 发布版菜单渲染、截图选择窗口物理尺寸。
每次完整结果保存在 artifacts/release-test/results.txt，核心结果在 artifacts/core-tests.txt。

## 桌面检查
通过 Windows Computer Use 实际操作自生成测试图片：
1. 打开标注窗口。
2. 拖动画笔，观察新增笔迹。
3. 选择橡皮擦穿过笔迹，确认仅穿过的位置被擦除。
4. 点击完成，确认文件更新和标注窗口关闭。
未使用用户照片作为测试样本。
