# 0.5 多屏、动效、视觉和分发检查 · 2026-10-23

## 已确认并修补

1. Card 在 Unloaded 后移除 Rendering 回调，缺少 Loaded 恢复，导致后续展开不再更新图片摆动。测试先复现再修补为成对、幂等的订阅。每次展开重新启动摆动；绳子增加阻尼弹跳，图片挂点跟随同一条抛物线，弹跳结束归零。
2. 旋转图片原先使用扩大后的外接矩形命中，透明角落会截获鼠标。改为反变换到真实边框局部坐标，再按圆角几何检测；不再使用可能过期的 IsMouseOver。取下按钮也按自身变换后的可见圆形区域检测。
3. 应用内截图原先由窗口 DIP 选区乘一个宽度比例再截断。改为直接记录物理屏幕坐标，裁剪与原图像素一一对应；绘制选区时才变换到 WPF 坐标。跨屏和负原点不再混入显示缩放。
4. 截图飞入改用实际窗口 PointFromScreen；取消拖拽回程原先混用 DIP 与另一屏幕的 DPI，现在位置和大小都在物理像素空间插值，终点来自真实可视边界。
5. 编辑、预览和视频裁剪窗口在触发操作的屏幕工作区居中并适配其 DPI；用户主动打开时请求前台、激活并短暂提高层级，随后恢复普通窗口。Windows 仍可能限制前台切换，尚未在真实长按中验证所有环境。
6. 用户选择黑白灰＋少量冷蓝，已替换带绿色倾向的主题色；图标改为几何叠片/衣夹与冷蓝点缀，托盘提供适配浅/深任务栏的单色资源。颜色选择器的文字箭头改为工具栏同风格的矢量折线。
