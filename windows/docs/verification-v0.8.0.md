# 0.8.0 图片篮子、桌面贴图与视觉更新

## 行为
取下/全部取下/左右取下/容量淘汰仅改变绳上展示，保留文件和篮子记录。显式回收站命令确认后删除，失败保留记录。篮子支持筛选、搜索、多选、预览、挂回、另存副本与独立自动挂图开关。置顶图片支持移动、缩放、编辑刷新、复制、回挂、关闭回篮子；游戏勿扰隐藏/恢复贴图。

旧数据迁移备份 settings.before-basket.json，仅发现 Inbox 现存媒体和已有记录。路径记录与缩略图加载分离：被占用/暂时无法解码的文件保留历史，篮子缩略图按需加载，启动仅载入原挂图。已被旧版送入回收站的文件不自动恢复。贴图位置本轮不跨重启保存。

## 图标和动效
imagegen 内置工具生成应用与独立托盘图标；工具不暴露模型选择，不能确认用户提及的 image2.5。应用：珊瑚衣夹、深蓝绳、蓝青山景、金色太阳与浅蓝精致底板。托盘：同意象的简化彩色图形。原图 Assets/IconSource；scripts/package-icons.py 只转换尺寸/ICO，不重新绘制。分别编码 16–256px 应用图标和 16–64px 托盘图标。
文字框辅助轮廓不进入导出。动效缩短拖尾、减小摆幅，显隐反向保留当前进度，主要动效遵循系统动画设置。原 B 组音效未改。

## 验收边界
测试使用工作区合成媒体与隔离设置。图片篮子/贴图进行 WPF 实际窗口与渲染验证；没有覆盖真实双屏热插拔、全部第三方拖放目标、长期数万图片历史压力或不同显卡下的主观动效体验。新图标美感与实际桌面动效仍以用户试用反馈为准。
