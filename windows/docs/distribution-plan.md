# 给朋友分发晾图

## 2026-10-24：已完成用户级安装器

当前推荐分发 `dist/Liangtu-0.6.3-Windows-x64-Installer-r2.zip`，或其中的 `Liangtu-0.6.3-Setup-x64-r2.exe`。应用仍为 0.6.3，安装器修订为 r2。用户选择小安装包、视频组件安装时联网下载。安装器约 49 MiB，自带 .NET；Jellyfin FFmpeg 视频组件另外下载约 65 MB，优先南京大学镜像，失败后依次尝试 Jellyfin 官方源和 GitHub 官方发布，所有来源校验相同固定哈希。也支持将原始组件 ZIP 放在安装程序旁边，校验后离线安装。提供中文向导、开始菜单、可选桌面快捷方式和卸载入口，默认不开机自启，卸载保留数据。36 项安装检查及 13 项切源/离线检查通过，细节见 [r2 安装验收](verification-installer-v0.6.3-r2.md)。尚未代码签名。

以下保留此前便携包规划作为历史说明。

## 现在：免安装试用包

采用 .NET 自包含 win-x64 发布，运行时随包携带；不要求朋友安装 .NET、Visual C++ 构建工具或其他开发环境。GlassNative 使用静态 C++ 运行库。ZIP 解压后运行 Start.cmd / Liangtu.exe，截图与标注开箱可用。

脚本 scripts/package-portable.ps1 从全新版本目录构建，包含 Windows Desktop 运行时、原生玻璃 DLL、语言资源、简明说明及第三方许可。随后生成逐文件 SHA-256 清单，并让发布后的 EXE 用 --verify-package 在不显示窗口、不访问用户数据的情况下验证运行时来源、文件完整性及原生库加载。ZIP 旁附 SHA-256 校验文件。

构建命令：powershell -File build.ps1。版本来自项目文件。相同版本的目录已存在时拒绝覆盖，避免正在运行的旧程序或其他文件混入发布包。更新 RuntimeVersion 参数后需要重新验证并发布；自包含运行时不会自动借用系统上更新的 .NET。

本版未附带 FFmpeg，视频功能为可选；图片功能不受影响。若以后需要完整视频包，应先明确 FFmpeg 二进制来源、编译配置与相应许可证，再单独打包，避免把开发电脑上的可执行文件随手塞进发布包。

## 试用反馈收集

先给少量朋友使用同一版本。反馈至少包含 Windows 版本、显示器分辨率/缩放/排列、截图来源（系统、Snipaste或应用内）、步骤与错误日志。多屏视觉、长按窗口前台、剪贴板竞争仍需要真实桌面验收。避免同时运行多版本；升级前退出旧版。

## 稳定后：用户级安装器

建议安装到当前用户 LocalAppData/Programs，创建开始菜单入口、可选桌面快捷方式，提供卸载入口。默认不要求管理员权限，不自动打开登录启动。数据继续放 LocalAppData/Liangtu；卸载是否删除图片和设置应由用户明确选择。

先保持手动更新，下载新版后退出旧版并替换程序；有稳定发行地址和签名后再考虑自动更新、回滚和签名校验。当前没有创建网站、公开发布、收费服务、自动更新服务器，也没有购买证书。

当前包未签名。校验和只验证传输/文件完整性，不能证明发行者身份。面对来源提示应核实版本与发送方，不应让朋友关闭系统安全功能。公开分发前再安排代码签名和发行流程。
