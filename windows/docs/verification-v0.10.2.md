# 0.10.2 内存优化验证

日期：2026-10-27。用户要求降低内存且保留现有功能与流畅度。

## 修改

- 历史解码缩略图使用 16MiB LRU。绳上图片与篮子实际实现的行有独立保护；保护对象可超过预算，保证正在看的内容和即时展开可用。
- 被淘汰的图片保留轻量预览；这些预览另受 2MiB 和 128项双重上限约束，超出后使用共享占位图。记录和原文件不变。宽高元数据独立保存，重新挂回及贴图尺寸不依赖占位图。
- 篮子容器加载、回收、数据切换与关闭都管理缩略图租约；旧图在后台恢复原显示精度。关闭后清除大图预览引用。
- 异步解码检测图片是否仍在收藏以及重载代次，防止删除/重新编辑后的旧结果写回。
- 原尺寸主题素材保留。未选主题从静态缓存移除；窗口仅申请当前主题纹理。实时玻璃仅由晴空主题使用，切换到其他材质释放其原生合成对象，切回可重新创建。
- 产品逻辑未加入强制 GC、工作集裁剪、动画降帧或原图压缩。

## 同负载对比

使用同一 MemoryChecks、Release/x64、同一台机器，旧版源码隔离保存在 artifacts/memory-optimization/baseline-source。测试数据为1920×1080合成 PNG 的不同文件路径；不接触用户收藏和剪贴板。两版均按同样时序展开、滚动、关闭窗口并测量。测量工具中的 GC 只用于比较保留资源，不进入应用启动或日常路径。

| 场景 | 旧版私有提交 MiB | 新版私有提交 MiB | 旧版解码图片 MiB | 新版解码图片 MiB |
|---|---:|---:|---:|---:|
| 空白启动 | 131.32 | 133.07 | 0 | 0 |
| 导入96张历史图片 | 205.47 | 151.06 | 74.05 | 16.93 |
| 滚动篮子 | 312.48 | 251.46 | 74.05 | 16.93 |
| 关闭篮子与编辑窗口 | 313.69 | 254.83 | 74.05 | 16.93 |
| 扩展到320张历史图片 | 484.09 | 249.62 | 246.83 | 17.43 |

320张场景私有提交量减少约48%，解码图片减少约93%。96张导入用时1304ms→1152ms；缓存中被淘汰的旧图恢复约7.24ms。热绳子刷新p95为0.07ms→0.06ms（布局调用耗时，不代表端到端桌面帧率）。

空白启动的基础开销没有明显下降。私有提交量包含系统承诺提供的内存，与任务管理器的专用工作集含义不同；以上数据不承诺所有机器、图库内容或长期操作序列有相同百分比降幅。

原始证据：

- 旧版：artifacts/memory-optimization/data-baseline-cb6831848edc41c298e72565e395b9e4/measurements.json
- 新版：artifacts/memory-optimization/data-optimized-0775b1dd646a4b10b146061038710a7a/measurements.json
- 新版20项内存检查全部通过；旧版按预期在缓存上限、预览与材质生命周期检查失败。
